# Rock Paper Scissors Game (PHP)

This is a web-based game built with PHP, HTML, CSS, and MySQL.

## 🚀 How to Run on a device

To play this game locally, you need a local server environment like **XAMPP**.

### 1. Prepare the Files
* Install [XAMPP](https://www.apachefriends.org/index.html).
* Download this repository and extract it into your XAMPP folder: 
  `C:/xampp/htdocs/rps_game/`

### 2. Set Up the Database
* Open XAMPP Control Panel and start **Apache** and **MySQL**.
* Go to [http://localhost/phpmyadmin/](http://localhost/phpmyadmin/).
* Create a new database named **rps_game**.
* Click on your new database, go to the **Import** tab, and select the `rps_game.sql` file from this project.
* Click **Go** at the bottom.

### 3. Connection Settings
* Ensure your `db.php` file matches your local XAMPP settings:
  - **Host:** localhost
  - **User:** root
  - **Password:** (blank)
  - **DB Name:** rps_game

### 4. Play the Game
* Open your browser and go to: `http://localhost/rps_game/index.php`
